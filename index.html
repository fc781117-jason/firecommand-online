常見故障排除｜定位、PDF、登入›
測試人員遇到定位、PDF 或登入問題時，請先依下列步驟排除；操作完成後重新整理本頁。

iPhone / iPad（Safari）

  1. 定位：設定 → 隱私權與安全性 → 定位服務 → Safari 網站，允許使用定位。
  2. PDF：若「匯出 PDF」沒有反應，使用「同頁列印 / 存 PDF」；再按分享 → 列印或儲存到檔案。
  3. 彈出式視窗：設定 → App → Safari → 暫時關閉「阻擋彈出式視窗」，完成匯出後可再開啟。

Android（Chrome）

  1. 定位：網址列左側圖示 → 權限 → 位置，選擇允許；若無法調整，重設網站權限後重開。
  2. PDF：使用「同頁列印 / 存 PDF」後，選列印 → 另存為 PDF。
  3. 彈出式視窗：若 Chrome 顯示已封鎖彈出式視窗，點「一律顯示」後再匯出。

定位校正原則

  1. 先以 Google 地址結果定位，再比對現場 GPS。
  2. 地址與 GPS 差距過大時，改用「點地圖設定中心」手動修正。
  3. 確認火場中心、入口與第一面後，再按「確認並鎖定案件中心」。

Google 地圖診斷

  1. 部署頁展開「定位診斷」，確認 API Key、Maps JavaScript、Places 與瀏覽器定位均為可用。
  2. 若顯示 Referer 或 API 權限錯誤，請確認 Google Cloud 已允許正式網域與目前測試網址。
  3. 正式版不再使用 OpenStreetMap；Google 地圖無法載入時會顯示明確錯誤，不會偷偷改用錯誤的行政區中心。
