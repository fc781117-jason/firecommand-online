# FireCommand v25｜指揮概要與直覺部署優化版

## 本版重點

1. 案件概要改為唯讀即時彙整頁。案件建立後不再提供重複手動修改，建物、火煙、受困、指揮權、戰情與部署資料改由流程 SOP、戰情及部署功能自動更新。
2. 新增「長官快速掌握」文字摘要，將案件地址、建物、火煙、人命、指揮權、人車水線、RIT 與最新戰情整合成可直接閱讀或簡要回報的段落。
3. 概要頁加入唯讀的外部戰術部署圖及建物內部作戰圖快照；修改必須返回部署頁，避免誤觸圖面。
4. AI 注意事項改為滿版自適應閱讀區，自動清除 Markdown 星號、井字號及程式碼符號，依標題、段落與必要條列呈現。
5. 「新增車輛」及「新增人員」合併為「新增分隊／人員／車輛」。大隊、單位只需選擇一次，接著登錄帶隊官、人數、狀態、任務及多台車輛。
6. 車輛代號提供 11、12、16、17、21、31、41、51、61、71、81、91 快選，並將「手動輸入／借用車輛」置於最上方。
7. 新增的人員及車輛會自動排列在建物右側待命區，車輛標籤直接顯示「單位＋車號」，可拖曳或先選取後點地圖部署。
8. 地圖新增「回復上一步」，涵蓋人車移動、拖放、刪除、水線建立與改接、危害標示、任務輪替及建物框移動／縮放／旋轉。
9. 水線改為圖面點對點操作：點來源車輛的「拉水線」，再點另一台車、人員編組或建物第一、二、三、四面。取消獨立水線填寫表單。
10. 水線標籤改為來源單位與車號，例如「淡水12 1線」，並在正式部署示意圖中同步顯示。
11. 建物中心框取消表格式設定，直接於地圖拖曳中心、大小與 360° 旋轉控制點；第一至第四面會隨建物框一起旋轉。
12. 保留 Google Maps 精準定位、Places 地址候選、GPS 比對、案件中心鎖定、自適應建物作戰圖、正式進度報告與同頁 PDF 返回功能。

## 操作原則

- 案件概要只負責掌握最新狀況，不作為資料輸入頁。
- 現場資料由「流程 SOP」、「戰情」、「部署」及「人車狀況」共同維護。
- 水線建立請先選擇可供水車輛，再點目標車輛、人員或建物四面。
- 建物框未鎖定時可移動、縮放與旋轉；完成方向校正後請鎖定。
- 所有圖面修改集中在部署頁，概要及報告只顯示快照。

## 發布

將本資料夾內的內容覆蓋 GitHub 專案根目錄，提交至 Vercel 使用的 Production Branch。部署完成後開啟：

`https://firecommand-online.vercel.app/api/maps-config`

確認：

- `enabled: true`
- `version: 25`

Google Maps Billing、Maps JavaScript API、Places API（New）、Geocoding API 與 `GOOGLE_MAPS_BROWSER_KEY` 沿用既有設定，不必重新建立。
