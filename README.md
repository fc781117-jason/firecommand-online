# FireCommand v23｜流程 SOP、火場代號與自適應建物作戰圖

本版以手機現場操作為核心，同時補強橫式平板與電腦寬螢幕。主要處理：回報稿只朗讀已確認資料、無線電代號與 Google 帳號名稱分離、流程 SOP 第二層專屬欄位、概要卡片可進入細部資料，以及建物縱向剖面／水平俯視圖在直式與橫式裝置上的自適應呈現。

## 主要更新

### 火場／無線電代號
- 首次建立帳號時必填火場／無線電代號，例如「淡水316」。
- 無線電回報稿固定使用火場代號，不再使用 Google 顯示名稱。
- 點左上角個人資訊即可修改火場代號與顯示稱呼。
- 舊帳號若尚未設定代號，登入後會主動提醒補填。

### 流程 SOP
- 左側「到場」改為「流程 SOP」。
- 到、建、火、人、支、初、破、警各自只顯示專屬的第二層確認事項。
- 未確認必要事項以紅色提示；部分完成為黃色；最低必要資料完成為綠色。
- 切換 SOP 卡片只改變操作畫面，續報稿會持續累積所有已確認資料。
- 未確認資料不會被寫進無線電續報稿。

### 地址與第一面
- 現場地址可直接修正。
- 地址變更會解除舊案件中心鎖定，提醒重新到部署頁確認 Google 地圖位置。
- 第一面可選：
  - 現場正面為火場第一面。
  - 律定指定位置／地址為火場第一面。
- 指揮站位置為獨立選填欄位。

### 回報稿
- 首次到達稿與正式續報稿分開顯示及複製。
- 正式續報只納入已確認項目。
- 未完成指揮權、未確認地址、未確認危險物、未完成 PAR 等內容只留在 APP 紅色提醒，不會對指揮中心朗讀。
- 續報固定使用一、到；二、建；三、火；四、人；五、支；六、初；七、破；八、警的分類。

### 概要卡片
- 建物、受困、車輛、人員、水線與戰情卡片可直接切換到對應細部頁面。
- 屬於真正換頁，不是同一長頁面的捲動定位。

### 自適應建物作戰圖
- 將原本容易誤解的「同步樓層／儲存建物作戰圖」切換按鈕，改為明確的顯示模式：
  - 縱向剖面。
  - 水平俯視繪圖。
  - 雙圖全覽（寬螢幕）。
- 「同步樓層」放回縱向剖面板內，作為真正的資料動作。
- 「儲存作戰圖」放回水平繪圖板內，選擇水平繪圖後可立即看到。
- 手機直式：一次顯示一個圖面並全寬操作。
- 手機橫式／橫式平板：繪圖區自動增高，工具列展開換行，減少水平拖動。
- 電腦／寬平板：預設雙圖全覽，左側縱向剖面、右側大面積水平俯視圖。
- 可手動切換成單獨水平繪圖，讓畫布佔滿整個內容寬度。
- 新增「全幅繪圖」，以同頁全畫面模式操作，並保留退出按鈕。
- 寬螢幕的樓層清單可獨立捲動，避免把整頁撐得過長。

## Google Maps 設定

本版沿用既有設定：

```text
GOOGLE_MAPS_BROWSER_KEY
```

Google Cloud 應啟用：

```text
Maps JavaScript API
Places API（New）
Geocoding API
```

正式網站限制：

```text
https://firecommand-online.vercel.app/*
```

發布後檢查：

```text
https://firecommand-online.vercel.app/api/maps-config
```

應顯示：

```json
"enabled": true,
"version": "23"
```
