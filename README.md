本版延續 v29，實戰與練習共用相同辨識、確認和資料更新流程。以白底、深藍字、青藍重點縮短手機操作路徑。

**先開啟 `SETUP_v30.html`：包含更新、Google／Firebase 登入與 AI 設定的七步教學。** 部署後亦可從登入首頁按「登入設定與檢查」。

## 日常操作

1. SOP → 初 → 部署 → 展開「文字回報」。用手機鍵盤語音輸入或直接打字。
2. 按「AI 辨識內容」；有需要也可在設定內改用「本機整理（非 AI）」。
3. 逐筆核對摘要，按「確認登錄」。需要改動時按「修改」，修改後再按確認；不必勾整頁。
4. 若水線需要先登錄相連車輛，卡片會顯示「同時登錄」的車號與面向，確認時一併寫入。
5. 已登錄一部分後按「輸入下一次回報」開始新回報，避免重新送出已處理的增員句。未完成項目可以在最近回報續處理。
6. 圖面移動一台相連的車，整組維持相對位置；若只想移動獨立車，先確認並解除其連線。移位不等於改接，進攻水線終點仍維持原指定。

## 登入最短路徑

- Google Cloud → Google Auth Platform → Clients → 既有 Web application → Authorized JavaScript origins：填完整正式 origin。
- Firebase → Authentication → Settings → Authorized domains：填主機名稱。
- Vercel → Environment Variables：`GOOGLE_WEB_CLIENT_ID` 填同一個 Web client ID，選 Production，儲存後重新部署。
- 正式網站 → `/login-help.html` → 檢查 → 返回首頁實際登入。

完整中英文選項、找不到選項時的替代入口、欄位內容與錯誤對照，均在 SETUP_v30.html。舊 firebaseapp.com 錯誤頁需關閉，再由固定正式首頁重新開始。

## 部署與驗證範圍

整包覆蓋原專案同路徑，保留原 Firebase 專案及 Vercel 設定，不要只更新 index.html。未設定 OPENAI_MODEL 時仍預設 gpt-4.1-mini；正式站已有的環境變數優先。依本次截圖，可沿用 gpt-5.4-mini，並新增 OPENAI_INTAKE_REASONING=low。
