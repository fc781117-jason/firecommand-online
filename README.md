# FireCommand v24｜現場快選與正式報告修正版

## 本版重點

1. 將開案、概要、流程 SOP 的建物樓層、起火樓層、火煙樓層、受困人數、編組人數及建物框尺寸改為下拉式或預設選項，取消需要精細點擊上下箭頭的數字輸入。
2. 火煙資料改為「樓層＋觀察面向＋煙量＋煙色＋火焰狀況」自動組句；補述可留空，不會自動顯示「無」或「未知」。
3. 回報稿會把舊資料中的「3」自動正規化為「3樓」。
4. 移除「首次到達回報」獨立稿件，只保留會隨已確認資料累積更新的續報稿。
5. 火場進度報告改為正式章節、次標題、段落與必要條列，不再把每一句包成獨立方框。
6. 報告第四節不再逐項列出入口、隔間、水線、起火點等繪圖工具紀錄；詳細位置由正式化附圖呈現。
7. OpenAI 報告模式修正為專用正式報告提示詞，禁止 Markdown 星號、井字號與粗體符號。
8. Google Maps v23 載入修正、自適應建物作戰圖、SOP 分頁與 PDF 同頁返回機制全部保留。

## 尚未啟用：演習／兵棋推演模式

本版未加入演習模式，避免影響目前正式勤務功能。後續建議拆成獨立工作區，至少包含：

- 教官／北海角色與受測角色分流。
- MSEL 腳本匯入、人工校對、事件時序、開始、暫停、下一事件、跳過與臨時插入事件。
- 系統壓力測試模式：AI 依腳本自動填入案件資料。
- 正式受測模式：AI 只發布情境，不代替受測人員填寫；所有反應由人員操作。
- 依評分表逐項蒐集操作證據、時間、回報與圖面更新，再由 AI 提出建議分數，教官保留最終覆核權。
- MAYDAY、RIT／IRIT、PAR、水源、REHAB、媒體發布及返隊清點等專項事件。

## 發布

將本資料夾內容覆蓋 GitHub 專案根目錄並提交至 Production Branch。Vercel 完成部署後，開啟：

`https://firecommand-online.vercel.app/api/maps-config`

確認 `enabled: true` 且 `version: 24`。
