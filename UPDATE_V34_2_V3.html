FireCommand v34.2 V3 更新方法

Production HOLD：本包先更新功能分支與 Preview；不要上傳到 main、不要按 Merge、不要重新設定 OAuth 或 Firebase Rules。

一、解壓

先在電腦解壓 firecommand_v34_2_v3_preview_update.zip。GitHub 網頁不會自動解壓 ZIP。

二、選功能分支

  1. 開啟 GitHub → fc781117-jason/firecommand-online。
  2. 按 Branch selector／分支選擇器。
  3. 選 feature/v34-2-tactical-simplification-v3，不要選 main。

三、上傳

  1. 按 Add file／新增檔案 → Upload files／上傳檔案。
  2. 上傳解壓後內容並保留 assets/、tests/ 等原路徑；不要多一層包名資料夾。
  3. 按 Commit changes／提交變更；目標仍須是功能分支。
  4. 不要按 Merge pull request／合併拉取請求。

四、Vercel Preview

  1. 開啟 Vercel Dashboard → FireCommand → Deployments／部署。
  2. 找到相同 branch／commit 的 Preview，等待 Ready／就緒。
  3. 使用合成或隔離資料驗收，勿在正式案件試刪除。

五、本輪不用改的設定

不需改 Google OAuth、Vercel 環境變數、Firestore Rules、Storage Rules，也不需資料庫 migration。

六、完成後檢查

  • 任務是下拉選單，其他才可自由輸入。
  • 未知人數可登錄，續報不念人數待補。
  • 部署首頁只有人員、車輛、圖面。
  • 戰術圖是消防示意畫布，A車→B車可建立水線。
  • 戰術圖示含起火點、瓦斯、高壓電、危險物、前進指揮所、休息區、救護區。
  • 4F 疏散可新增多戶，未知人口不當成0。

詳細結果請看 V34_UI_V3_STATUS.md 與 TEST_RESULTS.md。
