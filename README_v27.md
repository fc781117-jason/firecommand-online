# FireCommand v27｜連續演練、角色協作與快速部署

交付日期：2026-09-07。基準：本次工作區保留的 v26 完整原始碼。這是可供部署驗收的更新包，尚未更新使用者的 Vercel 正式站。

## 先看這三件事

1. **單人練習選「否，我要受測，由 AI 教官主持」**。房主是主受測者，不會顯示真人教官出題控制。
2. **真人帶訓選「是，我擔任真人教官」**。其他人加入後操作，教官掌握開始、暫停、採納回應、追加情境與結束。
3. **部署文字先預覽再套用**。可解析車對車供水、車到建物面向的水線及已明確提供的人數；不完整資訊會保留待確認。

## 安裝與更新

1. 保留現有 v26 部署作為回復點。
2. 將本資料夾內容更新至原 Vercel 專案。沿用原 Firebase 專案，無須重建案件。
3. 從本資料夾發布規則：`firebase deploy --only firestore:rules --project firecommand-online`。已附 `firebase.json`。
4. 保留原 `OPENAI_API_KEY`、`OPENAI_MODEL`、`GOOGLE_MAPS_BROWSER_KEY`、`GOOGLE_MAPS_MAP_ID`。API 金鑰只放 Vercel 環境變數。
5. 本版 AI API 增加登入與帳號啟用檢查。若使用其他 Firebase 專案，前端設定及伺服器 `FIREBASE_PROJECT_ID`、`FIREBASE_WEB_API_KEY` 必須同步設定。預設仍對應現有 firecommand-online 專案。
6. 確認頁首顯示 v27，`/api/maps-config` 回傳 `version: "27"`；重新整理頁面。
7. v26 尚在進行的練習房請完成後保留紀錄；**v27 請建立新房間開始測試**，避免把舊固定間隔腳本當作新制的評分紀錄。實戰資料持續沿用。

本次未操作正式站、未發布 Firestore 規則，未使用真實帳號呼叫付費模型。

## 單人練習

首頁 → 練習模式 → 建立新的練習房間：

- 教官選「否，我要受測，由 AI 教官主持」。
- 選角色、引導練習／自主測驗、情境來源及難度。
- 建立後按開始，系統補齊缺少的角色。
- 上方顯示本次情境與剩餘時間，另一欄顯示角色情報及真人操作紀錄。
- 在「我的判斷與處置」填實際內容；可使用語音，或先選提示範本再填完【】。
- 主受測者有效送出回應後，AI 規則引擎推進下一階段；逾時也會推進並記錄。
- 全部情境走完後顯示時效參考分、逾時、暫停次數、暫停時間、處置時間軸。可複製，或進入完整 AI 檢討。

「有效回應」在本版指非空白、有實際內容且移除待填範本；**不代表戰術正確**。時效分＝準時回應情境數÷總情境數×100。戰術品質仍需由教官依 SOP 審閱，AI 檢討是草稿。

暫停會凍結當前剩餘時間，恢復後接續，不重算整個階段；暫停次數與總時間獨立記錄，不直接當作戰術扣分。

## 真人教官與多人協作

- 開房者選擇擔任教官後，身分固定為教官。
- 其他同大隊已啟用帳號以六碼房號加入，可選指揮官、安全官、紀錄官、分區指揮官、單位帶隊官或觀察員。
- 教官可點情境建議、修改文字與 30–900 秒反應時間，追加至本次佇列。
- 教官按「採納回應／下一情境」推進；沒有回應時會記為跳過。
- AI 主持多人房中，房主是主受測者；其他角色回報進情報欄，不代替主受測者跳關。
- 真人佔有的角色不再由同角色 AI 發話。觀察員僅供觀察，不能送出受測回應。
- 角色回應優先使用設定的 AI 模型，失敗時標記為 AI 腳本。

### 同步邊界

房主瀏覽器執行情境推進，須保持開啟；多分頁以 Firestore 交易版本避免同一時刻重複推進。所有人讀取同一份情境狀態。背景、鎖屏或關閉不等於暫停；恢復後判定當前階段是否逾時，不連續跳完全部階段。若需休息請先按暫停。

本版尚未移至常駐伺服器主持，也沒有防作弊考場隔離；同大隊協作帳號可讀取房間腳本。適合練習與教官帶訓，不作正式甄試評分依據。

## 部署文字與旋轉

可測試：

> 淡水61供水給淡水11；淡水11第一面出兩線；竹圍4人第三面搜救。

1. 部署頁輸入文字 → 文字轉部署草圖。
2. 核對車輛、面向、人數、水線起終點與條數，可在表格修改或移除。
3. 按確認加入圖面；同名既有車輛沿用，新人車與水線批次新增。
4. 於地圖拖曳、修改，必要時使用復原。
5. 按旋轉建物 90°：新草圖的相對位置跟隨建物旋轉，水線以車輛／面向 ID 相連，所以連接對象不變。

原有實地定位點、人工拖曳確認的點維持地理位置；不會為了調整面向而移動現地座標。第一面面向重新定義與實際車輛移位應分別操作。尚未支援的消防栓節點、樓層路徑及含糊描述會列待確認，保留文字並交由原繪圖工具補完。

## SDS 與化災參考

更多 → AI 建議與化災資料 → 化災資料與 SDS。

- 提供職安署、環境部及 PHMSA ERG 官方入口。
- 可上傳 400 KB 內 PDF／圖片／文字，或填原文連結並貼上摘錄。
- AI 可擷取產品、廠商、CAS、UN、濃度、修訂日期及 16 項內容；未知維持未知。
- 人工核對後儲存：原檔／連結、摘要、版本、核對人與時間。原檔含 SHA-256 便於追溯。
- 本案件可依品名、CAS、UN 搜尋資料，優先展開危害、急救、滅火、洩漏、防護、反應性與運送資訊。
- 已核對資料會送入 AI 建議與檢討上下文，要求標示產品、版本、章節與來源。

目前提供「官方入口＋使用者提供文件的擷取與保存」，**並未串接外部即時 SDS 自動搜尋 API**。大檔案請使用來源連結及摘錄。AI 不應用一般物質資料替代不同濃度或配方的現場產品 SDS；資料衝突時先核對原文。
